# Marco Movie Lite · 电视端兼容适配版

作者：Pilipala。GPL-3.0-only。目标 Android 4.0 / API 14 以上电视与机顶盒。

当前是面向旧款安卓电视/盒子的独立轻量版，包名 `com.pilipala.marcomovie.lite`，可与完整版并存，不读取完整版账号或配置。
本产品只是工具，不含任何影视资源、配置源或账号。用户需自行合法获取配置与内容访问权限。

## 已实现的电视端适配能力

### 1. 编译与旧系统包体规范
- 使用真实 Android 4.0 (`API 14`) 平台 `android.jar` 作为编译 `bootclasspath`；通过 `D8 --min-api 14` 生成单 DEX (`classes.dex`)，并使用同时兼容旧安卓与新系统的 v1 + v2 签名。
- 声明 `LEANBACK_LAUNCHER` 与 `touchscreen=false`，声明 `configChanges="keyboardHidden|orientation|screenSize|uiMode"`，避免遥控器/方向切换重建页面。

### 2. 电视大屏多列网格与遥控器高对比焦点
- **统一顶部导航栏**：支持在 `首页片源`、`当前源`、`搜索`、`直播`、`历史`、`收藏`、`配置` 之间一键切换，按遥控器 `MENU` 键快速回首页、`SEARCH` 键直达搜索、快速连按 `UP` 键回到页面顶部。
- **高对比度焦点高亮**：所有卡片、横向分类胶囊、选集按钮、操作按钮均配备鲜明的琥珀金高亮描边 (`#FFF5B83D`) 与深色背景对比，解决旧版横向分类栏焦点不可见问题。
- **自适应多列布局**：
  - 电视/横屏下片源列表采用 2～3 列卡片网格（支持设为主源、置顶、上移、下移、删除）。
  - 影视目录、搜索结果、观看历史、我的收藏采用 4～5 列海报网格卡片（带右上角更新备注角标与副标题）。
- **低内存异步海报加载器 (`LiteImageLoader`)**：
  - 采用两阶段 `inSampleSize` 采样与 `Bitmap.Config.RGB_565` 解码，配合有界内存 `LruCache` 与本地磁盘缓存 (`cacheDir/lite_posters`)，兼顾大屏海报展示与 Android 4.x 低内存盒子稳定性。

### 3. 影视详情页与大剧集分组
- 顶部横幅卡片展示海报、年份/地区/类型/评分徽章、主演与导演、简介正文。
- 快捷操作栏支持：`▶ 立即播放 / 续播`、`♥ 加入收藏 / ★ 已收藏`、`⇅ 正序 / 倒序`、`默认播放线路`、`跨源换源`（自动在其它可用 CMS 片源中检索同名剧集并切换）。
- **多播放线路标签栏** + **剧集区间分组标签栏（`1-40集`、`41-80集`……）** + **多列选集网格**，解除旧版 150 集截断限制。

### 4. 遥控器屏幕字母/数字键盘与全站聚合搜索
- 内置适配方向键的 `A-Z` / `0-9` / `退格` / `清空` 屏幕快捷键盘，免去旧电视无遥控器输入法的困扰；同时保留系统输入框与历史搜索胶囊。
- 支持**搜索当前源**与**全站聚合搜索**（并发检索已启用 CMS 片源并展示来源角标）。

### 5. 观看历史、跨重启续播与我的收藏 (`LiteStore`)
- 自动记录每个剧集的片源、线路、集数与播放毫秒进度；首页顶部展示「继续观看」快捷入口，详情页与历史页支持一键续播与单条/全部清理。
- 支持剧集收藏夹本地持久化管理。

### 6. 电视直播 (`电视直播`)
- 自动解析导入配置中的 `lives` 列表（支持 `TXT` `#genre#` 分组格式、`M3U` `#EXTINF` 格式、`proxy://do=live&type=txt&ext=...` Base64 内联直播源）及手动添加自定义直播源地址。
- 提供分组标签切换、多列频道网格、多线路切换，以及直播播放界面下按遥控器**上下方向键直接换台**。

### 7. 电视播放器 OSD 与遥控器交互
- **自动隐藏 OSD 控制层**：无操作 4.5 秒自动隐藏顶栏与底栏；播放时按确认键立即暂停/继续，按左右方向键快退/快进（单击 ±15 秒，长按按 `25s -> 45s -> 75s -> 120s` 阶梯加速）。
- **底部遥控器工具栏**：播放时按上/下方向键或菜单键呼出并聚焦底部控制按钮，支持 `暂停/播放`、`下一集`、`选集`（弹窗列表）、`换线路`（弹窗列表）、`比例：适应 / 铺满 / 16:9 / 4:3`、`代理：自动(HTTPS/HLS) / 始终开启 / 关闭`，并支持播完自动连播下一集。

### 8. 配置/CMS 兼容扩展与本地回环媒体代理 (`LiteCatalog` & `LiteMediaProxy`)
- **CMS 与配置格式**：同时支持 JSON CMS (`type=1`) 与 MacCMS XML (`type=0`)；支持明文 JSON、带注释 JSON、`GZIP` 压缩配置、`**` Base64 配置与 `2423` Hex-AES-128-CBC 加密配置；自动提取片源级 `ua`、`header`/`headers` 与 `ext.headers`。
- **本地回环媒体代理 (`LiteMediaProxy`)**：在 `127.0.0.1` 随机端口提供随机令牌保护的本地 HTTP 代理，使用系统安全连接组件，并在系统支持时启用 TLS 1.2、自动注入片源自定义 `User-Agent` / `Referer` 请求头、转发 MP4 `Range` 字节范围请求 (`206 Partial Content`)，并自动重写 `.m3u8` HLS 播放列表中的分片与密钥相对地址，不关闭任何证书或主机名校验。
- **Emby 媒体库**：可从「配置 → 连接 Emby 媒体库」添加，支持媒体库浏览、搜索、剧集详情、播放进度回传与原始媒体直连。

## 验证与本地构建

沿用完整版的 JDK / build tools 配置；设置 `MARCOMOVIE_API14_JAR` 指向官方 API 14 `android.jar`。

```powershell
# 构建标准版与候选版（含 Conscrypt TLS 1.2 + IJK/FFmpeg 软解）
python -X utf8 scripts/build_lite.py
python -X utf8 scripts/build_lite.py --candidate

# 运行 API 14 LiteProbe 编译/D8 检查 + 53 项 TV Lite JVM 自动化测试
python -X utf8 scripts/test_lite_jvm.py

# 在 API 14 专用模拟器 (emulator-5580) 上运行真机/模拟器集成测试
python -X utf8 scripts/test_lite_device.py
```

## 边界说明

- Lite 版坚持零动态代码执行原则：对于 `type=3` 等需要运行外部 JAR / JS / Python 爬虫的源，保留在列表中并明确标注「暂不支持」，不伪装成空片库。
- `LiteMediaProxy` 可协助旧系统播放器桥接支持 TLS 1.2 的 HTTPS / HLS 媒体流及自定义请求头，但底层音视频解码仍受旧电视硬件解码器或候选版 FFmpeg 编码格式支持范围限制。

### HTTPS 支持边界

标准 Lite 使用系统 TLS 组件，不包含 Conscrypt。Android 4.1–4.4 在设备支持时显式启用 TLS 1.2；Android 4.0 的系统组件不支持 TLS 1.2，遇到这类服务会报告不兼容，不能保证现代 HTTPS 播放。实验候选版的 Conscrypt 2.5.2 最低支持 Android 4.4，不可作为 API 14 兼容证明。证书和主机名校验始终保留。
